# Ezventure

Co-op 3D voxel adventure RPG. Single file game: `index.html`.

## Co-op (sampai 3 pemain)
Buka lewat GitHub Pages (https://sikhsanf.github.io/ezventure/). Pemain 1: Menu atau tombol Co-op → **Buat room** → kasih kode 4 huruf. Pemain 2 & 3: Co-op → masukin kode → **Gabung**. Monster dikendalikan perangkat pembuat room; XP & koin dibagi saat monster kalah. Koneksi lewat PeerJS (WebRTC).
